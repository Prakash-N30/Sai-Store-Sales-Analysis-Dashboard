# Sai-Store-Sales-Analysis-Dashboard

## Project Overview

This project demonstrates how Microsoft Excel can be used to build an interactive business intelligence dashboard for retail sales analysis.

## Objectives

* Analyze sales performance
* Track order status
* Identify top-performing regions
* Compare customer demographics
* Visualize sales channels
* Support business decision-making

## Tools Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Slicers
* Conditional Formatting
* Data Cleaning

## Dashboard Highlights

* Sales vs Orders Analysis
* Sales by Gender
* Sales by Age Group
* Order Status Distribution
* Top 5 States by Sales
* Sales Channel Performance
* Interactive Filters

* Data Cleaning
